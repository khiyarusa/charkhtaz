# منابع دادهٔ خودروهای افزوده — Extra vehicle sources

این سند مکمل `docs/VEHICLE_DATA_SOURCES.md` است و فقط پنج خودروی افزودهٔ
`src/vehicles/extra-cars.ts` را پوشش می‌دهد.

- **تاریخ بازیابی همهٔ نشانی‌ها:** ۲۰۲۶-۱۱-۱۲ (2026-11-12)
- **روش:** هر مقدار «تأییدشده» از صفحه‌ای خوانده شده است که در ستون منبع آمده.
  هر مقداری که با «تخمین» علامت خورده، دادهٔ رسمی قابل‌دسترس نبوده و از
  مهندسی معکوسِ ابعاد، نسبت‌های رایج یا تست جاده تخمین زده شده است.
- **سطح اعتماد:** بالا = مشخصات رسمی/برگهٔ فنی؛ متوسط = منبع بازار یا
  بازسازیِ سازگار؛ پایین = تخمین مهندسی.

**یادداشت مدل‌سازی:** سه خودروی دستی (`206`، `Tondar 90`، `MX-5`) کلاچ
واقعی و `auto: null` دارند. دو خودروی خودکار (`Tara`، `Corolla`) کلاچ
`null` و `AutoSpec` کامل دارند. برای کرولای CVT، شش نسبت ثابت فقط یک
تقریب گسسته از بازهٔ قرقره‌هاست تا منطق تعویض دندهٔ موجود بازی بدون تغییر
کار کند؛ این تقریب در جدول بالا صریحاً تخمین علامت خورده است.

**تصاویر و پالت‌ها:** رنگ بدنه‌ها بر پایهٔ رنگ‌های رایج بازار انتخاب شده‌اند
(آبی دولفینی ۲۰۶، سفید صدفی تارا و کرولا، نقره‌ای تندر، قرمز Soul Red
ام‌ایکس-۵). مقادیر `beltRatio`/`roofRatio`/`hoodRatio`/`trunkRatio` و
مختصات `EXTRA_SILHOUETTES` طراحی اصلی همین مخزن‌اند و از هیچ تصویر
بیرونی کپی نشده‌اند. برای ۲۰۶، چون `CarArt['kind']` فقط `sedan`/`suv`/`sport`
را می‌پذیرد، نزدیک‌ترین آرکیتایپ یعنی `sedan` انتخاب شده است؛ شکل واقعی
هاچ‌بک در `EXTRA_SILHOUETTES` حفظ شده است.
